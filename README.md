# Routh–Hurwitz Stability Analysis

A MATLAB project implementing the **Routh–Hurwitz stability criterion** to analyze the stability of continuous-time systems without explicitly solving for their roots.

## Features

- Implement the Routh–Hurwitz algorithm from scratch.
- Optimize the implementation to improve computational efficiency.
- Compare stability results with MATLAB's `roots()` and `eig()`.
- Evaluate time and space complexity through experiments.

## How to Run

1. Clone or download this repository.
2. Open the MATLAB Live Script (`.mlx`).
3. Run the sections to execute the implementation and experiments.

## Methods Compared

| Method | Approach |
|---|---|
| Routh–Hurwitz | Determine stability from the Routh array |
| `roots()` | Calculate polynomial roots |
| `eig()` | Calculate matrix eigenvalues |

## Purpose

This project explores the implementation and optimization of a classical control systems algorithm, connecting theoretical stability analysis with practical computational experiments.
